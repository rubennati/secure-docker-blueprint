Every stack the repository ships is listed here, grouped by what you want done rather
than by the directory it sits in. Several groups hold more than one tool for the same
job on purpose, and the order inside a group is alphabetical, not a ranking.

Each entry states what has been checked on a host, or that nothing has: a stack
listed here has been written and validated, and the second line says how far past
that it has gone. A guide, where one exists, is in the sidebar under
[Infrastructure](/infrastructure/) or [Applications](/applications/).
