Every stack the repository ships is listed here, grouped by what you want done rather
than by the directory it sits in. Several groups hold more than one tool for the same
job on purpose, and the order inside a group is alphabetical, not a ranking.

Each entry shows facts, not a grade: the pinned version and when upstream released
it, whether upstream has released a newer one, the CRITICAL and HIGH findings the
upstream images carry, and when the stack last ran on a host — *with a restore* where
a backup of its data came back. A host run tests the setup; when the pin has moved
since, the entry names the version that ran. Every stack meets the security baseline,
because CI enforces it. A guide, where one exists, is in the sidebar under
[Infrastructure](/infrastructure/) or [Applications](/applications/).
