Vaultwarden is a self-hosted, Bitwarden-compatible password manager. It is not a casual application — it stores credentials, and operating it responsibly requires understanding backup and restore before anything else.

## What this guide will cover

This is a placeholder for the first full operator reference guide on this site. When complete, it will cover:

- Installation and initial setup
- Configuration and admin access
- Backup — what to back up and how often
- Restore — testing that backups actually work before you need them
- Updates — how to update safely
- Troubleshooting — common problems and how to diagnose them

The restore step is not optional. A Vaultwarden instance with no tested restore path is an unfinished setup.

## Repository

Compose files and configuration are in [`apps/vaultwarden/`](https://github.com/rubennati/secure-docker-blueprint/tree/main/apps/vaultwarden) in the repository.
