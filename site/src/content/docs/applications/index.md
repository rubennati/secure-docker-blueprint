This section lists application guides that are ready to use from the Operator Site. Guides here cover operation — not just installation — including setup, ongoing use, backup responsibility, and updates.

## Available now

### Vaultwarden

A self-hosted password manager compatible with Bitwarden clients. This is the first complete application guide on the Operator Site. It covers first-time setup, hardening after account creation, backup scope, restore responsibility, and updates.

[Go to the Vaultwarden guide →](/applications/vaultwarden/)

## Why only one guide?

Guides are added when they cover the full operating path, not just how to start a container. A useful guide must address what to back up, what restore looks like, and how to update without data loss. That takes time to verify. One complete guide is more useful than a list of incomplete ones.
